
# OWASP Juice Shop – Manual QA Testing Portfolio

## Project Overview
This repository contains my practical QA testing work on OWASP Juice Shop, a deliberately vulnerable web application designed for security training and testing.

The project demonstrates my hands-on experience in manual software testing, test documentation and defect identification.

## Project Objectives
- Understand application requirements and workflows.
- Design and execute detailed test cases.
- Identify and document functional defects.
- Perform functional, regression, and UI testing.
- Validate application behavior and user interactions.
- Improve software quality through structured testing.

## Testing Scope
- Functional Testing
- UI/UX Testing
- Positive and Negative Testing
- Boundary Value Analysis
- Regression Testing
- Smoke Testing

## Tools & Technologies
- **Test Management & Documentation:** Microsoft Excel
- **Defect Tracking:** GitHub Issues
- **Version Control:** Git & GitHub

## Repository Structure
- `test-plan/` – Test planning and testing scope.
- `test-cases/` – Test scenarios and detailed test cases.
- `bug-reports/` – Identified defects and bug documentation.
- `evidence/` – Screenshots and testing evidence.
- `summary-report/` – Test execution summary and results.

## Project Status
**Status:** In Progress

Test case preparation and execution are ongoing. Documentation, defect reports, and test results will be updated as testing progresses.
