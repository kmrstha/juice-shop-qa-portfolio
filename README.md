# Juice shop QA Portfolio

Manual QA project on OWASP Juice Shop, a deliberately vulnerable we shop.

It shows how I plan, design, execute and report testing.



# About me

Kumar Shrestha, QC Engineer focused on web application testing. I have worked as a QC Engineer since January 2026. This project demonstrates my test planning, test case design, defect reporting and test summary skills.



# Application under test

* App: OWASP Juice Shop (run locally)
* URL: http://localhost:3000
* Version: v20.3.0
* Browser and OS: Chrome, Windows 11



# Scope

Registration and login, search, basket, checkout, feedback and complaint forms.



# Contents

* test-plan/ : test plan and feature list
* test-cases/ : test cases with expected and actual results
* bug-reports/ : defects found, with steps and evidence
* evidence/ : screenshots and recordings
* summary-report/ : final test summary
