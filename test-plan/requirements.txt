QUESTIONS AND POTENTIAL DEFECTS

Q-01: The password advice lists five rules but "12345" and "abcdefgh" are accepted, so none of the advice is enforced. Which is intended: the advice, the 5-40 character message or both? (BUG-01, REQ-REG-12)
Q-02: The password field stops input at 40 characters but the repeat password field accepts more. With 41 characters typed in both, "Passwords do not match" is shown and registration is blocked. (BUG-02, REQ-REG-07)
Q-03: Does the server reject a password longer than 40 characters when it is sent directly without the browser? To test with postman in the API testing project.
Q-04: The password counter shows "10/20" at 10 characters and "40/20" at 40. The limit shown (20) does not match the allowed maximum (40). The denominator never changes. (BUG-03, REQ-REG-18) Open point: [does the repeat password field show a counter and what limit does it show?]
Q-05: After 6th consecutive failed logins, no lockout, delay or warning appeared. Is lockout or rate limiting intended? Without it, passwords can be guessed by repeated attempts. (Security observation, no requirement yet)
Q-06: The Expiry Year field offers only years from 2080. A card expiring before 2080 cannot be entered. Is this range intended? (Potential defect, REQ-PAY-12)
Q-07: The Forgot password fields show"/20" and accept any number of characters, registration stops at 40. Is the length rule intended to differ? (Potential defect, REQ-FPW-12, REQ-FPW-13)
Q-08: Searching for characters shows different products whose names and descriptions do not contain it. Is this intended?
Q-09: Each review shows the author's email address to all visitors, including logged-out users. Is this intended?
Q-10: Link Image accepts a URL typed by the user. Which URLs are intended to be accepted? (Security observation, to review in the security part of the project.)
Q-11: Clicking Set with an empty username field removes the existing username with no message. Is this intended? (Defect candidate, REQ-PRF-05)
Q-12: Clicking Upload Picture shows the raw response {"error": "File is not passed"} and no file chooser is available. (Defect candidate, REQ-PRF-07, REQ-PRF-09)
Q-13: Submitting a valid image URL with Link Image does not change the profile picture. (Defect candidate, REQ-PRF-12)
Q-14: Clicking Link Image with an empty field or with text that is not a URL leaves the profile picture area showing a picture that is not loaded, with no error message. (Defect candidate, REQ-PRF-13, REQ-PRF-14)
Q-15: The tracking page does not show the delivery status ("In Transit") that is shown in Order History. Should it? (Question, REQ-ORH-06, REQ-ORH-07)
Q-16: The tracking page shows "Bonus Points Earned: 0". Is 0 expected for this order? (Question, REQ-ORH-11)
Q-17: Change Password accepts a new password identical to the current password. Is this intended?

OBSERVATIONS
- The password advice says "lower character" and "upper character" instead of "lowercase letter" and "uppercase letter".
- The password counter appears only after 5 characters are entered.
- The same message, "Invalid email or password", is shown for an unregistered email and a wrong password. This does not reveal which emails exist.
- The delivery option text shows "1 Days".
- The mobile number message reads "Mobile number must match 1000000-9999999999 format.", which reveals the accepted range as 7 to 10 digits.
- An expired card cannot be tested, because no past year can be selected.
- The feedback form masks the author's email as "***", but the reviews show the full author email to all visitors. The two features handle the same data differently. (See Q-09.)
- When a file that is not a PDF is selected, no message is shown. The Submit button is disabled with no explanation.
- No confirmation message is shown after a username is set.
- No limit was found on the username length.
- The tracking page is headed "Search Results - [order ID]" instead of a tracking title.
- Expected Delivery is written "1 Days".
- The order confirmation shows the customer's full email address.
- Deleting a saved address happens immediately, with no confirmation prompt.
- With no saved addresses, the page shows only the "Add New Address" button and no message.
