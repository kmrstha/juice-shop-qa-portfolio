
# Test Plan Documentation

## Project
OWASP Juice Shop – Manual QA Testing

## Overview
This folder contains the test planning documentation for the OWASP Juice Shop application. It defines the testing objectives, scope, approach, resources and schedule for the project.

## Objectives
- Verify application functionality against expected behavior.
- Identify functional defects and usability issues.
- Validate positive and negative user scenarios.
- Ensure critical application workflows work as expected.
- Document and track identified defects.

## Testing Scope
- Functional Testing
- UI/UX Testing
- Positive and Negative Testing
- Boundary Value Analysis
- Smoke Testing
- Regression Testing

## Testing Approach
Testing will be performed manually using predefined test scenarios and test cases. Actual results will be compared with expected results and identified defects will be documented with supporting evidence.

## Tools
- Microsoft Excel – Test case documentation
- GitHub – Version control and project documentation

## Test Deliverables
- Test Plan
- Requirements Documentation
- Feature List
- Test Scenarios and Test Cases
- Defect Reports
- Test Execution Evidence
- Test Summary Report

## Project Status
In Progress

Test planning, test case preparation and execution are ongoing. Documentation will be updated as testing progresses.
